A deterministic, rule-based Werewolf agent written in Python's standard library. It parses public claims and check reports, scores each claimant against roles revealed by deaths and exiles, coordinates village votes, protects credible seers, and plays werewolf with partner-matched night kills and tightly timed counter-claims. It makes no model calls, so the same served views and trial seed reproduce the same actions.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8890 python3 main.py
```
